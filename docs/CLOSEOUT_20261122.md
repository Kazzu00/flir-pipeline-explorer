Para repetir E2E localmente, instalar primero el backend core en un checkout
independiente mediante `uv sync --locked`. Definir `FLIR_AUDIT_BACKEND` con su
raíz real; el test utiliza su `.venv` de Python 3.11. Después, desde este frontend:

```powershell
npm ci
npm run lint
npm run typecheck
npm run test
npm run build
npm run format:check
npm run test:e2e
```

Ejecutar desde la ruta física si el checkout se abre mediante un enlace de
directorio de Windows: Prettier rechaza el patrón `.` cuando es un enlace.
